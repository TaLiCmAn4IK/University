System Requirements

64 bit

 

  • amd64(x86-64) CPU
  • Computer with one of the following operating systems: Microsoft Windows 10 (64bit) and 11 (64bit), Ubuntu 20.04 LTS (64bit) and 22.04 LTS (64bit), or macOS 10.14 or newer.
  • 4GB of free RAM
  • 1.4 GB of free disk space
  • Display resolution: 1920 x 1080
  • Language fonts supporting Unicode encoding (if viewing in languages other than English)
  • Latest video card drivers and operating system updates
  • Internet connectivity (if using the Multiuser feature or tutorials)

32 bit

 

  • x86 compatible CPU
  • Computer with one of the following operating systems: Microsoft Windows 10 (32bit)
  • 2GB of free RAM
  • 1.4 GB of free disk space
  • Display resolution: 1920 x 1080
  • Language fonts supporting Unicode encoding (if viewing in languages other than English)
  • Latest video card drivers and operating system updates
  • Internet connectivity (if using the Multiuser feature or tutorials)
Packet Tracer does not limit the amount of memory that is used to create and configure devices. So if a user, or more importantly an author, creates complex PKA and PKT files using large networks with complex protocols running may require up to 2 gigabyte or more of memory to run effectively. If you are creating activities for PT, please be careful of creating issues like STP loops as they might greatly increase memory requirements. By creating files like this, you may cause Packet Tracer to operate unreliably or even crash.
