# Сборка установщика Flux

## Шаг 1. Подготовка приложения

Опубликуй приложение в режиме Release с self-contained (не нужно ставить .NET 8 на машину пользователя):

```bash
dotnet publish Flux.csproj -c Release -r win-x64 --self-contained true -p:PublishSingleFile=false -o publish
```

В папке `publish` появится `Flux.exe` и все нужные DLL.

## Шаг 2. Установи Inno Setup

Скачай и установи Inno Setup: https://jrsoftware.org/isdl.php

## Шаг 3. Скомпилируй установщик

Открой файл `Flux.iss` в Inno Setup Compiler → File → Compile (или F9).

На выходе будет `Output/FluxSetup.exe` — это и есть установщик.

## Шаг 4. Дистрибуция

`FluxSetup.exe` можно отправить кому угодно. При установке:
- создаст ярлык в меню Пуск
- опционально создаст ярлык на рабочем столе
- зарегистрирует приложение в «Программы и компоненты» для удаления
- не требует прав администратора

## База данных

Приложение использует встроенную БД **SQLite** — отдельный сервер не нужен.
При первом запуске файл базы создаётся автоматически:

```
%LOCALAPPDATA%\Flux\flux.db
```

Это работает на любом компьютере «из коробки», без установки SQL Server и без
правки `appsettings.json`. Логи приложения — там же, в `%LOCALAPPDATA%\Flux\logs`.

Два клиента, запущенные на одном ПК под одним пользователем Windows, используют
один и тот же файл `flux.db` и видят очередь, лобби и матчи друг друга.

При необходимости расположение БД можно переопределить, указав строку подключения
SQLite в `appsettings.json` → `ConnectionStrings:Flux`
(например `"Data Source=D:\\flux.db"`).

## Ошибка «Эта программа не поддерживает версию Windows»

Если у получателя установщик выдаёт эту ошибку — причина в проверке архитектуры,
а не в версии Windows. Раньше в `Flux.iss` стояло `ArchitecturesAllowed=x64`, что
**исключало ARM64-машины** (ноутбуки на Snapdragon / Windows on ARM): на них установщик
отказывался запускаться этим сообщением.

Сейчас в `Flux.iss` используется `x64compatible` — установка разрешена на любой ОС,
способной выполнять x64-код (обычный x64 и ARM64 с эмуляцией). Чтобы новое ключевое
слово сработало, **компилируй установщик в Inno Setup 6.3 или новее**
(скрипт сам выбирает синтаксис по версии компилятора, но старые сборки не знают
`x64compatible`). После обновления Inno Setup пересобери `FluxSetup.exe`.

Установка на настоящую 32-битную Windows невозможна: приложение публикуется как
`win-x64` (self-contained) и физически требует 64-битную систему.
